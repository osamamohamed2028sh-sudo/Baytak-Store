# Baytak Store - Static Version
متجر ثابت باستخدام HTML وCSS وJavaScript فقط.

## التشغيل
افتح `index.html` في المتصفح أو ارفع محتويات المجلد إلى GitHub Pages.

## تعديل رقم واتساب
افتح `app.js` وعدّل:
`const WA_NUMBER = "201554283448";`
اكتب الرقم بصيغة دولية بدون + وبدون صفر البداية.

## تعديل المنتجات والأسعار
افتح `products.js`. كل منتج له:
- id
- name
- category
- price (بالجنيه)
- image
- description

## ملاحظات مهمة
- الأسعار الحالية أسعار افتتاحية مقترحة وليست عروض أسعار مؤكدة من المورد أو ضمانًا لأقل سعر في السوق.
- راجع سعر الشراء والشحن والتغليف قبل اعتماد السعر النهائي، وحدد هامش ربحك.
- الصور مستخرجة من ملف الصور المرفق، وبعضها قد يحتاج استبدالًا بصورة أوضح أو تصويرًا أفضل.
- الطلبات تُرسل إلى واتساب فقط، ولا توجد قاعدة بيانات أو مخزون تلقائي في هذه النسخة.
